CommonGround developer docs

CommonGround is software for community land trusts (CLTs). These pages explain how it is built, for a developer who joins or forks the project.

The system, step by step

A community land trust buys land and keeps it for good. It sells the homes on that land to households with modest incomes and leases them the land under a ground lease. The lease caps the resale price, so the home stays affordable for the next buyer. Each step of that work has its own bounded context in the code.

  1. 1. The trust gets land and builds or buys homes on it.

  2. 2. Households apply to buy, and the trust picks one for each home.

  3. 3. The household buys the house and leases the land. Later they resell at a capped price.

  4. 4. The trust helps owners keep their homes.

About these pages

The pages are static HTML with no build step. Open docs/design/index.html from disk or serve the folder with any static file server. Diagrams use Mermaid 11.4.1 from jsDelivr, so they need a network connection.

  • docs/design/docs.css holds the styles for light and dark mode.
  • docs/design/nav.js builds the header, the sidebar, the Previous and Next links and the cards on this page. Its SITE list is the one place that lists the pages.

To add a page: copy an existing context page and add it to SITE in nav.js, or remove planned: true from its entry. The sidebar, the Previous and Next links and its card on this page follow from that. The sidebar lists every <section id> in <main> by its <h2>, so a page needs no contents list of its own. Check it at 390px wide: the page must not scroll sideways.
