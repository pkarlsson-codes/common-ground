# View Open Resales

1. User navigates to Resales (in the Sales focus)
2. The table lists each resale in progress, most recent notice first: home, homeowner, Notice Date, Option Window End and the days left, or "Window passed"
3. With none in progress, the page says "Resales start from recording a homeowner's intent to sell on their ground lease."
4. User clicks a row; the home's ground lease opens in its detail panel
