# View Open Resales

1. User navigates to Resales (in the Sales focus)
2. The table lists each resale in progress, most recent notice first: home, homeowner, Notice Date, Step (Notice, Appraised, Option Exercised or Finding a Buyer), Option Window End and the days left, or "Window passed". Once the trust has decided, the window column is blank
3. With none in progress, the page says "Resales start from recording a homeowner's intent to sell on their ground lease."
4. User clicks a row; the resale opens in its detail panel

A resale leaves the list when it is withdrawn, the buyback closes, or the buyer's purchase closes.
