# Deny Eligibility

1. User navigates to Applicant Selection
2. User clicks a row for an application in the Submitted phase to open the detail panel
3. In Workflow Actions, user clicks "Deny Eligibility"
4. "Deny Eligibility" panel opens with Denied Date defaulted to today
5. User enters a required Reason and optionally adjusts Denied Date
6. User clicks "Deny Eligibility" (disabled until Reason and Denied Date are set)
7. Toast: "Eligibility denied"
8. Panel closes, application moves to the Eligibility Denied phase and no further workflow actions are available
