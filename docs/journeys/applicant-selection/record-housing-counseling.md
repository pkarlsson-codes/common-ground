# Record Housing Counseling

1. User navigates to Applicant Selection
2. User clicks a row for an application in the Active or Waitlisted phase to open the detail panel
3. In the Buyer Preparation Checklist, user clicks "Record" next to Housing Counseling
4. "Record Housing Counseling" panel opens with Completed Date defaulted to today
5. User enters a required Certification Number and Counselor Organization, and optionally adjusts Completed Date
6. User clicks "Record Counseling" (disabled until Certification Number, Completed Date, and Counselor Organization are all set)
7. Toast: "Housing counseling recorded"
8. Panel closes, the Housing Counseling checklist item is marked done
