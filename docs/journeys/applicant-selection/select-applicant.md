# Select Applicant

1. User navigates to Applicant Selection
2. User clicks a row for an application in the Waitlisted phase to open the detail panel
3. In Workflow Actions, user clicks "Select Applicant"
4. "Select Applicant" panel opens with Selected Date defaulted to today
5. User enters Home ID, Land Parcel ID, and Ground Lease Template ID, and a Purchase Price
6. User optionally adjusts Selected Date
7. User clicks "Select Applicant" (disabled until Home ID, Land Parcel ID, Ground Lease Template ID, Purchase Price, and Selected Date are all set)
8. Toast: "Applicant selected"
9. Panel closes, application moves to the Selected phase; the detail panel now shows Selected Date and links to open the selected land parcel and home
