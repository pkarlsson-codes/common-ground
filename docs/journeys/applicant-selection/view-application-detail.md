# View Application Detail

1. User navigates to Applicant Selection
2. User clicks a row in the Applicant Selection table
3. Detail panel opens titled with the household's primary contact, showing phase (Submitted, Approved, Selected, Denied, or Withdrawn), submitted at/by, primary contact phone, declared household size, declared annual income, declared accessibility need (as captured at submission), approved date, selected date, denial reason (if any), and withdrawal reason (if any)
4. If the applicant has been selected, the panel shows "Open Selected Land Parcel" and "Open Selected Home" links
5. A Household Members section lists each member's name, email, and phone, marking the primary contact
6. A Buyer Preparation Checklist shows the household's current Housing Counseling, CLT Orientation, and Mortgage Prequalification, each marked done or pending; while the application is Submitted or Approved, pending items offer "Record" (and Mortgage Prequalification offers "Update")
7. If the household has a mortgage prequalification, a Mortgage Prequalification section shows lender name, prequalified amount, and expiry date
8. A Workflow Actions section shows the actions available for the current phase: Submitted offers Approve Application, Deny Application, and Withdraw Application; Approved offers Deny Application and Withdraw Application; otherwise "No actions available for this phase" — selecting an applicant is done from the home, see [Select Applicant From Home](select-applicant.md)
9. User closes the panel
