# Approve Eligibility

1. User navigates to Applicant Selection
2. User clicks a row for an application in the Submitted phase to open the detail panel
3. In Workflow Actions, user clicks "Approve Eligibility"
4. "Approve Eligibility" panel opens with Approved Date defaulted to today
5. User optionally adjusts Approved Date and enters optional Notes
6. User clicks "Approve" (disabled until Approved Date is set)
7. Toast: "Eligibility approved"
8. Panel closes, application detail refreshes to reflect the new phase
