# Initiate Purchase Workflow

1. User navigates to Purchase Workflows
2. User clicks "Initiate Workflow"
3. "Initiate Purchase Workflow" panel opens with Purchase Price defaulted to 150000
4. User searches for and selects a Ground Lease
5. User enters Buyer Full Name and Buyer Email (required), and optionally Buyer Phone in E.164 format (e.g. +11231231234)
6. User optionally adjusts Purchase Price
7. User clicks "Initiate Workflow" (disabled until a Ground Lease is selected)
8. Toast: "Purchase workflow initiated"
9. Panel closes, new workflow appears in the Purchase Workflows table in the Initiated phase
