# Initiate Purchase Workflow

Purchases has no toolbar entry point for starting a workflow. A workflow starts when a home selection is completed, by priority or by lottery, using the ground lease template, purchase price and selected date entered when completing it. See [Select Household by Priority](../home-selections/select-household-by-priority.md) and [Draw Selection Lottery](../home-selections/draw-selection-lottery.md). The user stays on the selection page; the new workflow appears on Purchases.
