# Initiate Purchase Workflow

Purchases no longer has a toolbar entry point for starting a workflow. A workflow is now always initiated from one of two places:

1. **New purchase** — starts when a home selection is completed, by priority or by lottery, using the ground lease template, purchase price and selected date entered when completing it. See [Select Household by Priority](../home-selections/select-household-by-priority.md) and [Draw Selection Lottery](../home-selections/draw-selection-lottery.md). The user stays on the selection page; the new workflow appears on Purchases.
2. **Resale** — starts from a Ground Lease's "Start Resale" action. See [Start Resale Workflow](../resale-workflows/start-resale-workflow.md).

A resale lands the user on Purchases with the new workflow's detail panel open. See [View Purchase Workflow Detail](view-purchase-workflow-detail.md).
