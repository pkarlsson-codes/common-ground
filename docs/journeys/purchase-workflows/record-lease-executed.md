# Record Lease Executed

1. User navigates to Purchases
2. User clicks a row for a non-terminal workflow to open the detail panel
3. In Purchase Tracks, user expands the Lease Execution track (only expandable while pending)
4. User enters Signed Date (required)
5. User clicks "Record Lease Executed"
6. Toast: "Lease executed"
7. Track collapses and shows "Signed {date}"; the Lease Execution track is marked complete
