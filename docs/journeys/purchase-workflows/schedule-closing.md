# Schedule Closing

1. User navigates to Purchases
2. User clicks a row for a workflow where all five other tracks (Eligibility, Financing, Inspection, Title, Lease Execution) are complete
3. In the Closing track, user enters Scheduled Date (required)
4. User clicks "Schedule Closing"
5. Toast: "Closing scheduled"
6. Closing track shows "Scheduled for {date}"; the workflow moves to the Closing Scheduled phase
