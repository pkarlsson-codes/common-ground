# View Purchase Workflow Detail

1. User navigates to Purchase Workflows
2. User optionally filters the table by phase (All Phases, Initiated, In Progress, Closing Scheduled, Closed, Failed, Withdrawn, Stalled) or by ground lease
3. User clicks a row in the Purchase Workflows table
4. Detail panel opens titled with the buyer's full name, showing purchase price and phase in the subtitle
5. If the workflow is Stalled, a Stalled banner shows the stalled reason and resolution target date (if set)
6. Panel shows Phase, Purchase Price, buyer Email and Phone (if present), an "Open Ground Lease" link, Failure Reason (if failed), Withdrawal Reason (if withdrawn), Closing Notes (if closed), and Created (date/time)
7. Unless the workflow is Closed, Failed, or Withdrawn, panel shows Purchase Tracks (Eligibility, Financing, Inspection, Title, Lease Execution, and Closing), each marked complete or pending, and an Exception Actions section
8. User closes the panel
