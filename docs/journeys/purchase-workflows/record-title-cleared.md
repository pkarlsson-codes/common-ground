# Record Title Cleared

1. User navigates to Purchase Workflows
2. User clicks a row for a non-terminal workflow to open the detail panel
3. In Purchase Tracks, user expands the Title track (only expandable while pending)
4. User enters Cleared Date (required) and optional Title Company
5. User clicks "Record Title Cleared"
6. Toast: "Title cleared"
7. Track collapses and shows "Cleared {date}" (plus title company if entered); the Title track is marked complete
