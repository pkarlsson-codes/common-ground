# Start Application

For a household that's already registered, e.g. one returning after a withdrawn or denied application.

1. User opens the household detail from Households
2. User clicks "Start Application" on the Next Step card (shown at the Ready stage when the household has no open application), or "Start Application" under "More actions" while the household is still at Intake
3. An application is submitted for the household, capturing its current size, income and accessibility as declared at submission
4. Toast: "Application started"
5. The new application appears under Connected Records in the Submitted phase, and the Next Step card offers "Open Application" instead
