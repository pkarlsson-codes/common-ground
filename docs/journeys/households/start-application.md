# Start Application

For a household that's already registered, e.g. one returning after a withdrawn or denied application.

1. User opens the household detail from Households
2. User clicks "Start Application" (only shown when the household has no open application)
3. An application is submitted for the household, capturing its current size, income and accessibility as declared at submission
4. Toast: "Application submitted"
5. The new application appears under "Applications" in the Submitted phase, and "Start Application" is replaced by "Open Active Application"
