# Find Household

1. User navigates to Households
2. Table lists every household, newest first: Primary Contact, Email, Size, and Readiness ("Ready" when housing counseling and CLT orientation are recorded and the mortgage prequalification hasn't expired; otherwise "Not ready")
3. User types in "Search by member name or email"; the table filters as they type, matching any member of the household, not just the primary contact
4. User clicks a row to open the household detail
