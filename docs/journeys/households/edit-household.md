# Edit Household

Changes apply to the household from now on. Applications already submitted keep the size, income and accessibility declared at submission.

1. User opens the household detail from Households
2. To change circumstances, user clicks "Edit Circumstances", changes Annual Income ($) and/or "Accessibility accommodations required", and clicks "Save Circumstances" (or "Cancel")
3. Toast: "Circumstances updated"; Annual Income and Accessibility Need show the new values
4. To change a member, user clicks "Edit" on their row, changes Full Name, Email and/or Phone, and clicks "Save Member"; invalid phone numbers show an inline error
5. Toast: "Member updated"; the row shows the new details. If the member is the primary contact, the panel title, the Households table and the household's applications show the new name and email
6. To add a member, user clicks "Add Member", enters Full Name, Email and Phone (all required), and clicks "Add Member"
7. Toast: "Member added"; the member is listed and Household Size goes up by one
8. To remove a member, user clicks "Remove" on their row (not offered for the primary contact), then "Confirm Remove" under "Remove {name} from the household?" (or "Cancel")
9. Toast: "Member removed"; the member is gone and Household Size goes down by one
