# Record Housing Counseling

Readiness belongs to the household, so it can be recorded whether or not the household has an open application.

1. User opens the household detail from Households, or via "Open Household" on an application's detail
2. In the Buyer Preparation Checklist, user clicks "Record" next to Housing Counseling
3. "Record Housing Counseling" panel opens with Completed Date defaulted to today
4. User enters a required Certification Number and Counselor Organization, and optionally adjusts Completed Date
5. User clicks "Record Counseling" (disabled until Certification Number, Completed Date, and Counselor Organization are all set)
6. Toast: "Housing counseling recorded"
7. Panel closes, the household's Housing Counseling checklist item is marked done

Pressing Escape (or Close or Cancel) with typed input asks "Discard changes?" before closing. See [Close an overlay](../navigation/close-an-overlay.md).
