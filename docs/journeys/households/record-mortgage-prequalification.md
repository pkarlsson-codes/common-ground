# Record Mortgage Prequalification

Readiness belongs to the household, so it can be recorded whether or not the household has an open application.

1. User opens the household detail from Households, or via "Open Household" on an application's detail
2. In the Buyer Preparation Checklist, user clicks "Record" (or "Update" if a prequalification already exists) next to Mortgage Prequalification
3. "Record Mortgage Prequalification" panel opens
4. User enters Lender Name, Approved Amount, and Expiry Date (all required)
5. User clicks "Record Prequalification" (disabled until all three fields are set)
6. Toast: "Mortgage prequalification recorded"
7. Panel closes, the household's Mortgage Prequalification checklist item is marked done showing lender name, prequalified amount and expiry date

Pressing Escape (or Close or Cancel) with typed input asks "Discard changes?" before closing. See [Close an overlay](../navigation/close-an-overlay.md).
