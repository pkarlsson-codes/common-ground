# Record CLT Orientation

Readiness belongs to the household, so it can be recorded whether or not the household has an open application.

1. User opens the household detail from Households, or via "Open Household" on an application's detail
2. In the Buyer Preparation Checklist, user clicks "Record" next to CLT Orientation
3. "Record CLT Orientation" panel opens with Completed Date defaulted to today
4. User optionally adjusts Completed Date
5. User clicks "Record Orientation" (disabled until Completed Date is set)
6. Toast: "CLT orientation recorded"
7. Panel closes, the household's CLT Orientation checklist item is marked done

Pressing Escape (or Close or Cancel) with typed input asks "Discard changes?" before closing. See [Close an overlay](../navigation/close-an-overlay.md).
