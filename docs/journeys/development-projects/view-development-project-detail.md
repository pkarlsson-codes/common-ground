# View Development Project Detail

1. User navigates to Development Projects; the table lists projects newest first with Name, Parcel, Type, and Status
2. Optionally, user types in the search box to filter projects by name or description (case-insensitive)
3. User clicks a row in the Development Projects table
4. Detail panel opens titled with the project name, subtitled with its type and status, showing status, type, and description
5. For a Rehabilitation project, panel lists the project's homes (home type and size), each with an "Open Home" link
6. Panel shows an "Open Land Parcel" link
7. User clicks "Open Land Parcel" to navigate to the project's land parcel, or "Open Home" to navigate to one of its homes
