# View Development Project Detail

1. User navigates to Development Projects
2. User clicks a row in the Development Projects table
3. Detail panel opens showing status, projected start date (if set), projected end date (if set), actual completion date (if set), budget (if set), and description (if set)
4. Panel shows an "Open Land Parcel" link
5. User clicks "Open Land Parcel" to navigate to the project's land parcel
