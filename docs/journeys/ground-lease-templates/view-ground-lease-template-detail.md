# View Ground Lease Template Detail

1. User navigates to Ground Lease Templates
2. User clicks a row in the Ground Lease Templates table
3. Detail panel opens showing status (Active or Inactive), resale formula, and term (years)
4. Depending on the formula, the panel shows Appreciation Share, Index Type, Baseline Index, and/or Annual %
5. Panel shows Improvements Cap if one is set, and Covenant Terms if present
6. Panel shows Created (date/time)
7. User closes the panel
