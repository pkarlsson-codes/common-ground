# View Ground Lease Template Detail

1. User navigates to Ground Lease Templates
2. User optionally narrows the table (sorted by name) by typing in the search box (matches template name, case-insensitive) or by status
3. User clicks a row in the Ground Lease Templates table
4. Detail panel opens (header shows term and status) showing status (Active or Inactive), resale formula, and term (years)
5. Depending on the formula, the panel shows Appreciation Share, Index Type, Baseline Index, and/or Annual %
6. Panel shows Option Window (days), Monthly Lease Fee with its Land Use Fee and Repair Reserve Fee, Improvements Cap if one is set, and Covenant Terms if present
7. Panel shows Created (date/time)
8. User closes the panel
