# Restore Ground Lease Template

1. User navigates to Ground Lease Templates
2. User filters the status dropdown to "Inactive" and/or searches by name to find an Inactive template
3. User clicks the template's row to open the detail panel
4. User clicks "Restore"
5. Toast: "Template restored"
6. Panel closes; template's status becomes Active in the Ground Lease Templates table

If restoring fails, the panel stays open and shows the error.
