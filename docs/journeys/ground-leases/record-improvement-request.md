# Record Improvement Request

The homeowner must ask the trust before altering or adding to the home, and the trust must reply in writing within two weeks (Art 7.3). Staff record each request on the lease. An approved and finished improvement can add a credit to the resale price (Art 10).

1. User opens a ground lease (see [View Ground Lease Detail](view-ground-lease-detail.md)) and clicks "Record Request" in its Improvements section (Active leases only)
2. "Record Improvement Request" panel opens, showing the homeowner and the home
3. User enters Received On (default today, not in the future), Description (required; what the homeowner will build or change) and Estimated Cost ($, required, above zero)
4. User optionally adds plans or quotes (choose or drop; PDF or image; several allowed)
5. User clicks "Record Request", or "Cancel"
6. Toast: "Improvement request recorded". The panel closes. The Improvements section lists the request as Waiting for decision, and an Improvement request to decide item shows on Today, due two weeks after Received On
7. If a plans upload fails, the panel stays open with the error and nothing is recorded. If the uploads work but recording fails, trying again reuses the uploaded files, so Documents gets no second copy
