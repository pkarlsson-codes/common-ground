# Withdraw Improvement Request

For when the homeowner drops the work, before the trust decides or after approval and before it is completed.

1. In the Improvement Request panel (see [View Improvement Request](view-improvement-request.md)) of a request waiting for a decision or approved, user clicks "Withdraw"
2. "Withdraw Improvement Request" panel opens with Reason (required)
3. User clicks "Withdraw", or "Cancel"
4. Toast: "Request withdrawn". The request shows Withdrawn and leaves Today. An approved credit no longer counts: work done later needs a new request
