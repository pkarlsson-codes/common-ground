# Deny Mortgage Request

1. In the Mortgage Request panel (see [View Mortgage Request](view-mortgage-request.md)) of a request waiting for a decision, user clicks "Deny"
2. "Deny Mortgage Request" panel opens with Reason (required; it is printed in the letter), for example "Total debt after closing would be 112% of the purchase option price; the lease allows 90%."
3. User clicks "Deny", or "Cancel"
4. Toast: "Request denied". The request shows Denied with the reason and a "Print Letter" button, and leaves Today
5. "Print Letter" opens the letter in a new tab with the print dialog: today's date, the homeowner's name and the home, "Mortgage loan not permitted", the lender, purpose and principal, the reason, that the homeowner may send a new request on other terms, and the trust's sign-off, with "cc: {lender}"
