# View Ground Lease Detail

1. User navigates to Ground Leases
2. User optionally searches by homeowner name or email (case-insensitive) and filters by status (All Statuses, Active, Inactive); the table lists newest leases first
3. User clicks a row in the Ground Leases table
4. Detail panel opens titled with the homeowner's name (populated automatically for leases created from a purchase workflow closing), showing status (Active or Inactive), resale formula, and term (years)
5. Depending on the formula, the panel shows Appreciation Share, Index Type, Baseline Index, and/or Annual %
6. Panel shows Improvements Cap if one is set, Start Date, Term, homeowner Email and Phone (if present), and Covenant Terms (if present)
7. Panel shows an "Open Home" button and an "Open Land Parcel" button, and Created (date/time)
8. User closes the panel
