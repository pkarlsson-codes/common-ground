# Approve Mortgage Request

The trust's written permission for the loan (Art 8.1, 8.3).

1. In the Mortgage Request panel (see [View Mortgage Request](view-mortgage-request.md)) of a request waiting for a decision, user clicks "Approve". The button is disabled until the request has its appraisal, with "Add the loan's appraisal first." beside it
2. "Approve Mortgage Request" panel opens with the debt check repeated
3. Within the cap: no fields; user clicks "Approve"
4. Above the cap: the panel says "Total debt after closing is above the lease's cap of X%." and asks Reason (required), for example a refinance of the first loan that lowers the monthly payment. User enters it and clicks "Approve Above Cap"
5. Toast: "Request approved". The request shows Approved with the figures and reason, a "Print Letter" button, and leaves Today until its expected closing has passed
6. "Print Letter" opens the permission letter in a new tab with the print dialog: today's date, the homeowner's name and the home, "Permission for a mortgage loan", the lender, purpose, principal, rate and term, the purchase option price, the cap and the total debt as a % of the price, that the permission is for these terms only and a loan on other terms needs a new request, and the trust's sign-off, with "cc: {lender}"
