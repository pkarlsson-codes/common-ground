# Approve Improvement Request

For when the trust agrees to the work and names the credit it will count at resale, up to the lease's improvements cap.

1. In the Improvement Request panel (see [View Improvement Request](view-improvement-request.md)) of a request waiting for a decision, user clicks "Approve"
2. "Approve Improvement Request" panel opens showing the description and Estimated Cost, the lease's Improvements Cap ("No cap on this lease, so no credit will count" when none), and the Confirmed Improvements the lease already has
3. User enters Pre-Approved Credit ($, default the lesser of Estimated Cost and the room left under the cap; zero up to Estimated Cost), Approved On (default today, not before Received On) and optional Notes
4. When the credit plus the confirmed improvements already on the lease go past the cap, the panel says "Only $X of this can count; the lease's cap is $Y." The user can still approve
5. User clicks "Approve", or "Cancel"
6. Toast: "Request approved". The request shows Approved, leaves Today, and offers "Print Letter" and "Record Completed". A $0 credit approves the work and counts nothing
7. "Print Letter" opens a print page in a new tab with the date, the homeowner's name, the home, the work approved, the Pre-Approved Credit, and the sentence that the credit counts only after the trust receives the receipts and confirms the finished work
