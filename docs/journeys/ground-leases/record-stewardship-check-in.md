# Record Stewardship Check-In

1. User navigates to Ground Leases
2. User optionally searches by homeowner name or email, then clicks a row in the Ground Leases table to open the detail panel
3. In the Stewardship Check-Ins section, user reviews prior check-ins (date, notes, recorded by), most recent visit first
4. User enters Check-In Date (default today) and Notes (required)
5. User clicks "Record Check-In"
6. Toast: "Check-in recorded"
7. New check-in appears in the Stewardship Check-Ins list in date order (at the top when it is the most recent visit), form resets
