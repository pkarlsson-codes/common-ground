# Record Stewardship Check-In

1. User navigates to Ground Leases
2. User clicks a row in the Ground Leases table to open the detail panel
3. In the Stewardship Check-Ins section, user reviews prior check-ins (date, notes, recorded by)
4. User enters Check-In Date (default today) and optional Notes
5. User clicks "Record Check-In"
6. Toast: "Check-in recorded"
7. New check-in appears at the top of the Stewardship Check-Ins list, form resets
