# Record Mortgage Loan Closed

For when an approved loan has closed. The loan becomes a permitted mortgage on the lease.

1. In the Mortgage Request panel (see [View Mortgage Request](view-mortgage-request.md)) of an approved request, or from Confirm closing on a "Mortgage loan closing to confirm" item on Today, user clicks "Record Loan Closed"
2. "Record Loan Closed" panel opens with Closed On (required, default the expected closing date when it has passed, otherwise today; not in the future, not before the approval), Notice Address for the lender (optional), and a checkbox per current permitted mortgage: "Paid off by this loan" (each checked for a Refinance, unchecked otherwise)
3. User clicks "Record Loan Closed", or "Cancel"
4. Toast: "Loan recorded closed". The request shows Closed. In the Mortgages section the new loan appears, permitted "Request" on the approval date, with its lender, principal and notice address; each ticked mortgage shows "Paid off {closing date}"
