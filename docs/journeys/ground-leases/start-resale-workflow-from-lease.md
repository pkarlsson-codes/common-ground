# Start Resale Workflow From Lease

1. User navigates to Ground Leases
2. User optionally searches by homeowner name or email, then clicks a row in the Ground Leases table to open the detail panel
3. In the Resale section, user clicks "Start Resale Workflow"
4. User is navigated to Resale Workflows with this lease pre-selected, opening the same resale wizard as clicking "Start Resale" on that lease's row
