# Set Insurance Requirements

The coverage the lease requires (Art 9.4): the home's replacement value, agreed before the lease starts, and liability insurance per occurrence. The trust may raise them, at most once a year, telling the homeowner at least 30 days before the policy renews. The app records the new amounts; staff write the letter.

1. User opens a ground lease (see [View Ground Lease Detail](view-ground-lease-detail.md)) and clicks "Set Requirements" in its Insurance section
2. "Insurance Requirements" panel opens with Replacement Value ($) and Liability per Occurrence ($), each filled with the current amount or empty when none is set, and Effective From (default today)
3. User changes either amount, or clears one to stop checking it. Each is zero or more
4. User clicks "Save Requirements", or "Cancel"
5. Toast: "Insurance requirements saved". The Insurance section shows the new amounts and the change in its history ("From {date}: replacement value $280,000.00, liability $300,000.00"). The current certificate is checked against the requirements in effect on its policy start date, so a raise effective after that date applies from the next certificate. An Insurance short of the lease item on Today comes or goes with the result
