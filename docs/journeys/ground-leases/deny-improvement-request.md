# Deny Improvement Request

1. In the Improvement Request panel (see [View Improvement Request](view-improvement-request.md)) of a request waiting for a decision, user clicks "Deny"
2. "Deny Improvement Request" panel opens with Denied On (default today, not before Received On) and Reason (required; it goes in the letter)
3. User clicks "Deny", or "Cancel"
4. Toast: "Request denied". The request shows Denied, leaves Today, and offers "Print Letter"
5. "Print Letter" opens a print page in a new tab with the date, the homeowner's name, the home, the work asked for and the reason
