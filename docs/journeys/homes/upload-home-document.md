# Upload Home Document

1. User navigates to Homes and opens a home's detail panel
2. User switches to the "Documents" tab
3. User clicks "Upload Document" (or drags a file directly onto the tab)
4. Upload form/drop zone opens; user selects or drops a File (title auto-fills from the file name, editable)
5. User enters Title (required) and optionally adjusts Sensitivity (Public, Internal, Confidential, Restricted; default Internal) and Retention (Transient, Standard3yr, LongTerm7yr, Permanent; default Standard3yr)
6. User clicks "Upload" (disabled until a file and title are set)
7. Toast: "Document uploaded"
8. Form closes, new document appears in the Documents list
