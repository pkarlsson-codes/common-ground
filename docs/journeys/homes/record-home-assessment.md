# Record Home Assessment

1. User navigates to Homes
2. User clicks a row in the Homes table to open the home's detail panel
3. In the Assessments section, user clicks "Add New Assessment"
4. Assessment form expands with fields for assessed value, assessment date, and optional condition notes
5. User enters an assessed value and assessment date, and optionally condition notes
6. User clicks "Record Assessment"
7. Toast: "Assessment recorded"
8. Form collapses, new assessment appears at the top of the Assessments list, and the Details tab's assessed value and last assessed date update to reflect it
