# View Home Detail

1. User navigates to Homes
2. User clicks a row in the Homes table
3. Detail panel opens showing the home type, bedrooms/bathrooms, and square footage in the header
4. "Details" tab shows status, whether the home is accessible, year built, assessed value, last assessed date, condition notes (if any), a link to the home's land parcel, and registered at
5. Panel also shows a Development Projects section listing projects on the home's parcel with their name and status
6. Panel also shows an Assessments section listing assessments newest first, starting from the initial assessment entered at registration, each with its date, assessed value, and appraiser name (or "—" if none was entered)
7. User can switch to the "Documents" tab to view, upload, remove, or version documents attached to the home
8. User closes the panel
