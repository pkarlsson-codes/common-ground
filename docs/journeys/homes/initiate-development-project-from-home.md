# Initiate Development Project From Home

1. User navigates to Homes
2. User clicks a row to open the home's detail panel
3. In the Development Projects section, user clicks "+ Initiate Project"
4. "Initiate Development Project" panel opens with the Land Parcel field pre-filled and locked to the home's parcel, and the Homes field pre-filled and locked to the current home
5. Project Type defaults to "Rehabilitation"
