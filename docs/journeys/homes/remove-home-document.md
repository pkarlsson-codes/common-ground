# Remove Home Document

1. User navigates to Homes and opens a home's detail panel
2. User switches to the "Documents" tab
3. User clicks "Remove" on a document row
4. A confirmation row opens beneath it: "Remove "{title}"? It can be restored later." with a required Reason field
5. User enters a reason and clicks "Confirm Remove" (disabled until a reason is entered), or clicks "Cancel" to keep the document
6. Toast: "Document removed"
7. Document disappears from the list (soft-deleted with the reason recorded, not permanently destroyed)
