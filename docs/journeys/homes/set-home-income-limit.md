# Set Home Income Limit

For when the subsidy behind a home sets a different limit than the one entered at registration.

1. User opens a home's detail panel (see [View Home Detail](view-home-detail.md))
2. User opens "More actions" and clicks "Set Income Limit"
3. "Set Income Limit" panel opens with the home's current limit: Percent of AMI, or "No income limit" ticked
4. User changes the percent (1 to 200) or ticks "No income limit", and clicks "Save"
5. Toast: "Income limit saved". The Details tab shows the new limit

A selection already open for the home keeps the limit it started with. To judge the candidates by the new limit, cancel the selection and start a new one.
