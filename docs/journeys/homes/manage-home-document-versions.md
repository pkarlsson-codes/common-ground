# Manage Home Document Versions

1. User navigates to Homes and opens a home's detail panel
2. User switches to the "Documents" tab
3. User clicks "Versions" on a document row; a Version History panel expands beneath it listing every version (version number, file name, size, uploaded date, "current" tag on the active version), each with a "DL" button to download that specific version
4. User clicks "Upload New Version" to add a new version: selects or drags a file, optionally enters a Version Note, and clicks "Upload"
5. Toast: "New version uploaded"
6. New version becomes current and appears at the top of the list
