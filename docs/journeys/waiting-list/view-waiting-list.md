# View Waiting List

1. User navigates to Waiting List
2. Header shows how many households are waiting
3. Table lists every application in the Approved phase, longest waiting first: Primary Contact, Size, Approved (date), Days Waiting, Prequalification Expires, Passed Over, and Readiness
4. Passed Over counts the home selections that completed with another household chosen while this household could have been selected. It follows the household, so it carries over if the household withdraws and applies again
5. Readiness shows "Needs re-verification" when the household's mortgage prequalification has expired (whether or not it has since been cleared), "Ready" when housing counseling and CLT orientation are recorded and the prequalification is still valid, and "Not ready" otherwise
6. User types in "Search by member name or email"; the table filters as they type, matching any member of the household
7. User clicks a row to open the household detail, where readiness can be recorded or the prequalification updated; the waiting list refreshes when the panel's changes are saved

Households join the waiting list when their application is approved ([Approve Application](../applications/approve-application.md)) and leave it when the application is selected for a home, denied, or withdrawn. A household whose purchase fails or is withdrawn returns to the list with its original approved date, so it keeps its place. Every household on the list is a candidate when a [home selection is started](../home-selections/start-home-selection.md).
