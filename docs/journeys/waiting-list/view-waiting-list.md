# View Waiting List

1. User navigates to Waiting List
2. Header shows how many households are waiting
3. Table lists every application in the Approved phase, longest waiting first: Primary Contact, Size, Approved (date), Days Waiting, Prequalification Expires, and Readiness
4. Readiness shows "Needs re-verification" when the household's mortgage prequalification has expired (whether or not it has since been cleared), "Ready" when housing counseling and CLT orientation are recorded and the prequalification is still valid, and "Not ready" otherwise
5. User types in "Search by member name or email"; the table filters as they type, matching any member of the household
6. User clicks a row to open the household detail, where readiness can be recorded or the prequalification updated; the waiting list refreshes when the panel's changes are saved

Households join the waiting list when their application is approved ([Approve Application](../applications/approve-application.md)) and leave it when the application is selected for a home, denied, or withdrawn.
