# Browse Document Library

1. User navigates to Documents, showing "Document Library" with all documents across the CLT portfolio
2. User optionally filters by tag (types into "Filter by tag…" and clicks "Apply", or clicks a tag chip on any document row) and/or by file type (All file types, PDF, Word (.doc), Word (.docx), JPEG, PNG)
3. User can click "Clear filters" to reset both filters
4. Each document row shows title, sensitivity badge (if set), current file name, size, version number (if >1), last modified date, and expiration date (highlighted amber if expiring within 30 days)
5. User clicks "Download" on a document row to download its current version in a new tab
6. User pages through results with "Prev"/"Next" when there is more than one page
