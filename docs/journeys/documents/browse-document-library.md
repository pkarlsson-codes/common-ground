# Browse Documents

1. User navigates to Documents, showing "Documents" with all documents across the CLT portfolio, most recently modified first
2. User optionally narrows the list:
   - Types into "Search by title" (case-insensitive match on the title)
   - Filters by tag: types into "Filter by tag…" and clicks "Apply" (or presses Enter), or clicks a tag chip on any document row
   - Picks a file type (All file types, PDF, Word (.doc), Word (.docx), JPEG, PNG, Text)
3. User can click "Clear filters" to reset search, tag, and file type
4. Each document row shows title, sensitivity badge, current file name, size, version number (if >1), last modified date, expiry ("expires {date}", or "expired {date}" once past; amber if expired or expiring within 30 days), and its tags
5. User clicks "Download" on a document row to download its current version in a new tab
6. User pages through results with "Prev"/"Next" when there is more than one page (20 per page)
7. User clicks a row to open the document's detail panel
