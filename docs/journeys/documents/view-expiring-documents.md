# View Expiring Documents

1. User navigates to Documents
2. If any documents expire within 90 days, a banner shows "{n} document(s) expiring within 90 days" with a "Show expiring" button
3. User clicks "Show expiring"; the library view is replaced by a list of documents expiring within 90 days (button label changes to "Show all")
4. Each row shows title, "Expires {date}" (or "Expired"), and file name; rows expiring within 30 days are highlighted amber
5. User clicks "Download" on a row to download its current version in a new tab
6. User clicks "Show all" to return to the filterable Document Library view
