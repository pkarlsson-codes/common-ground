# Mark a Reminder Done

1. On Today, a reminder's row shows the note and "Set for {date}"
2. User clicks **Mark done** on the row. The Reminders page offers the same button on reminders showing on Today
3. The toast says "Reminder marked done" and the reminder leaves Today
4. The [Reminders page](view-reminders.md) lists it under Done, with who marked it and when. Any member of the trust can mark any reminder done; if a colleague already did, nothing changes
