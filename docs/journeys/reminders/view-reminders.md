# View Reminders

1. User clicks **Reminders** in the sidebar, just below Today. Its count is how many reminders are on Today
2. The page lists every reminder the trust has set, in three sections:
   - **On Today**: the date has come and no one has marked it done, oldest date first, each with **Mark done**
   - **Upcoming**: set for a later day, soonest first
   - **Done in the last 30 days**: most recently done first, with who marked it and when. Older done reminders aren't listed
3. Each row shows the date, the note, the section it shows in on Today (Reminders when it was set in none) and who set it
4. **New reminder** in the header opens [Set a Reminder](set-a-reminder.md) with no section

Reminders can't yet be edited or deleted.
