# Workflows

Frontend, user-facing documentation of what happens when a staff user does something in the Management app. Not an API/backend reference — see the code for that.

One folder per page area (matches `src/CommonGround.Management.Web/src/pages/`), one file per user journey.

If a journey continues into another area's page, end the doc with a markdown link to the continuation doc instead of duplicating it there.

New workflow docs should follow `_TEMPLATE.md`.
