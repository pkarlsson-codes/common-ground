# View Stewardship Case Detail

1. User navigates to Stewardship, Lease Stewardship tab
2. User clicks a row in the queue table
3. Detail panel opens, titled with the homeowner's name (or a truncated ground lease ID if unknown), subtitle showing address, urgency (Urgent, High, Elevated, or Normal), and opened date
4. Panel shows an "Open Ground Lease" button, then three sections: Occupancy Verification, Property Inspection, Lease Violations
5. Actions taken in the panel update it, its urgency, and the queue immediately
6. User clicks "Open Ground Lease" to go to the lease's detail on the Ground Leases page, or closes the panel
