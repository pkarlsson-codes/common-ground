# Issue Violation Notice

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Lease Violations section, user finds an Identified violation card
3. User confirms Notice Date (defaulted to today) and confirms Cure Deadline (defaulted to 30 days from today)
4. User clicks "Issue Notice"
5. Toast: "Notice issued"
6. Violation moves to NoticeIssued status; card shows the notice date and cure deadline, flagged OVERDUE if the deadline has passed
