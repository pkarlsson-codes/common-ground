# Request Forbearance

1. User navigates to Stewardship, Foreclosure Prevention tab, and opens an active case's detail panel
2. User expands the case card, and in the Forbearance Requests section enters a required Lender Name and confirms Requested Date (defaulted to today)
3. User clicks "Request Forbearance"
4. Toast: "Forbearance requested"
5. Form resets; new request appears in the list awaiting an outcome
