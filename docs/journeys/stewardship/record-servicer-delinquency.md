# Record Servicer Delinquency

1. User navigates to Stewardship, Foreclosure Prevention tab, and opens an active case's detail panel
2. User expands the case card, and in the Delinquencies section confirms Servicer Name (defaulted to the case's trigger), Delinquent Months (defaulted to 1), and Recorded Date (defaulted to today)
3. User clicks "Record Delinquency"
4. Toast: "Delinquency recorded"
