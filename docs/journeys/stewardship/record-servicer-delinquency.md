# Record Servicer Delinquency

1. User navigates to Stewardship, Foreclosure Prevention tab, and opens an unresolved case's detail panel
2. In the Delinquencies section confirms Servicer Name (defaulted to the latest recorded servicer), Delinquent Months (defaulted to one more than the latest), and Recorded Date (defaulted to today)
3. User clicks "Record Delinquency"
4. Toast: "Delinquency recorded"
5. The delinquency is added to the Delinquencies list, and the table's Delinquency column shows it as "{servicer} · {months} mo"
