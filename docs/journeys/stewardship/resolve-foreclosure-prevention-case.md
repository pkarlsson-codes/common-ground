# Resolve Foreclosure Prevention Case

1. User navigates to Stewardship, Foreclosure Prevention tab, and opens an active case's detail panel
2. User expands the case card, and at the bottom, in the Resolution section, selects Resolution Outcome (Intervention Successful, Homeowner Sold, Cure Period Exercised, or Lease Terminated; defaults to Intervention Successful) and confirms Resolution Date (defaulted to today)
3. User clicks "Resolve Case"
4. Toast: "Case resolved"
5. Case status updates and the Resolution and other action forms no longer appear (case is no longer Active or Opened)
