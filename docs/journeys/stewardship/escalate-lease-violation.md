# Escalate Lease Violation

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Lease Violations section, user finds a NoticeIssued violation card
3. User enters a required Escalation Reason and confirms Escalation Date (defaulted to today)
4. User clicks "Escalate"
5. Toast: "Violation escalated"
6. Violation moves to Escalated status and appears under Resolved violations history
