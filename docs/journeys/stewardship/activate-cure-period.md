# Activate Cure Period

1. User navigates to Stewardship, Foreclosure Prevention tab, and opens an active case's detail panel
2. User expands the case card, and in the Cure Periods section enters a required LRA ID, confirms Activation Date (defaulted to today), and Cure Period in days (defaulted to 90)
3. User clicks "Activate Cure Period"
4. Toast: "Cure period activated"
5. Form resets; new cure period appears in the list showing the LRA ID and the date range from activation to cure deadline
