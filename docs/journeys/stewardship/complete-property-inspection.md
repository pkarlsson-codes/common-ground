# Complete Property Inspection

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Property Inspection section, with an inspection scheduled, user sets Occupancy Confirmed (checked by default), optionally enters Condition Notes, and confirms Completed Date (defaulted to today)
3. User clicks "Complete"
4. Toast: "Inspection completed"
5. Inspection moves out of the active slot into Past inspections history
