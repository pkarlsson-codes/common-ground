# View Stewardship Cases Queue

1. User navigates to Stewardship
2. Lease Stewardship tab is active by default, showing a table of every open stewardship case: Homeowner, Address, Occupancy {current year}, Active violations, Next inspection, Opened
3. The whole queue is sorted by urgency (most urgent first, then by open date): red if this year's occupancy verification failed/overdue or a violation notice's cure deadline has passed, orange if a violation is identified but not yet noticed, yellow if a pending verification's survey deadline is within 30 days or no verification exists yet for the year, otherwise neutral
4. User optionally types in the search box to filter by homeowner name or address
5. User optionally pages through results (20 per page)
6. If no cases are open, empty state shows "No active stewardship cases" / "Cases are opened automatically when a purchase closes."; if the search matches nothing, "No matching stewardship cases"
7. User clicks a row to open the case detail panel
