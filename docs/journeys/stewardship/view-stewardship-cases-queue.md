# View Stewardship Cases Queue

1. User navigates to Stewardship
2. Lease Stewardship tab is active by default, showing a table of open stewardship cases: Homeowner, Address, Occupancy {current year}, Active violations, Next inspection, Opened
3. Rows are sorted by urgency (most urgent first, then by open date): red if this year's occupancy verification failed/overdue or a violation notice's cure deadline has passed, orange if a violation is identified but not yet noticed, yellow if a pending verification's survey deadline is within 30 days or no verification exists yet for the year, otherwise neutral
4. User optionally pages through results with Previous/Next
5. If no cases are open, empty state shows "No active stewardship cases" / "Cases are opened automatically when a purchase closes."
6. User clicks a row to open the case detail panel
