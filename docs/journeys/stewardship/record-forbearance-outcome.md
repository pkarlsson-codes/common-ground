# Record Forbearance Outcome

1. User navigates to Stewardship, Foreclosure Prevention tab, and opens a case's detail panel
2. In the Forbearance Requests section finds a request with no outcome yet (outcomes can be recorded once the case is Active)
3. User selects Outcome (Granted or Denied; defaults to Granted), confirms Outcome Date (defaulted to today), and optionally enters Notes
4. User clicks "Record"
5. Toast: "Outcome recorded"
6. Request now shows "Outcome: {outcome} ({date})" (with notes if entered) instead of the form
