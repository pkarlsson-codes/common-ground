# View Foreclosure Prevention Case Detail

1. User navigates to Stewardship, Foreclosure Prevention tab
2. User clicks a row in the table
3. Detail panel opens, titled with the homeowner's name (falls back to "Foreclosure Prevention Case" if unknown), subtitle showing address and status
4. Panel shows a single case card (collapsed by default) with trigger, status, opened date, and resolved date if resolved
5. User clicks the card to expand it, revealing Delinquencies, Counseling Referrals, Forbearance Requests, Cure Periods, and (while the case is Active or Opened) a Resolution section
6. User closes the panel
