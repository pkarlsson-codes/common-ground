# View Foreclosure Prevention Case Detail

1. User navigates to Stewardship, Foreclosure Prevention tab
2. User clicks a row in the table
3. Detail panel opens, titled with the homeowner's name (falls back to "Foreclosure Prevention Case" if unknown), subtitle showing address and status
4. Panel shows an "Open Ground Lease" button, then a summary line with trigger, opened date, and resolved date and outcome if resolved
5. Below it: Delinquencies (every recorded servicer delinquency), Counseling Referrals, Forbearance Requests, and Cure Periods, each with its form while the case is unresolved, then the Resolution section
6. Actions taken in the panel update it and the table immediately
7. User clicks "Open Ground Lease" to go to the lease's detail on the Ground Leases page, or closes the panel
