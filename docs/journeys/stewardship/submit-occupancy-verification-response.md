# Submit Occupancy Verification Response

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Occupancy Verification section, with a Pending verification for the current year, user reviews the survey deadline (if set)
3. User sets Primary Resident (checked by default) and Sublet Disclosed (unchecked by default), optionally enters Major Changes, and confirms Submitted Date (defaulted to today)
4. User clicks "Submit Response"
5. Toast: "Verification response submitted"
6. Verification moves to Submitted status, awaiting Verify or Reject
