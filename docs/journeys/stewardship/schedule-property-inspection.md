# Schedule Property Inspection

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Property Inspection section, user clicks "+" (only available when no inspection is currently scheduled)
3. User confirms Scheduled Date (defaulted to today) and enters a required Inspector Name
4. User clicks "Schedule Inspection"
5. Toast: "Inspection scheduled"
6. Form resets and closes; section shows the scheduled inspection, flagged OVERDUE if the date has passed
