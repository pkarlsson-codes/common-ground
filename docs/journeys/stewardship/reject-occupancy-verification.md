# Reject Occupancy Verification

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Occupancy Verification section, with a Submitted verification, user enters a required Reason for Rejection and confirms Failed Date (defaulted to today)
3. User clicks "Reject"
4. Toast: "Verification failed"
5. Verification moves to Failed status; section shows the status badge and reason
