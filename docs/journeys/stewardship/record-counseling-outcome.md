# Record Counseling Outcome

1. User navigates to Stewardship, Foreclosure Prevention tab, and opens a case's detail panel
2. In the Counseling Referrals section finds a referral with no outcome yet
3. User selects Outcome (Counseling Completed, Homeowner Unresponsive, or Not Eligible; defaults to Counseling Completed) and confirms Outcome Date (defaulted to today)
4. User clicks "Record"
5. Toast: "Outcome recorded"
6. Referral now shows "Outcome: {outcome}" instead of the form
