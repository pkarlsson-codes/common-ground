# Identify Lease Violation

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Lease Violations section, user clicks "+"
3. User selects Violation Type (Occupancy, Unpermitted Alteration, Physical Condition, or Lease Term Violation; defaults to Occupancy), enters a required Description, and confirms Identified Date (defaulted to today)
4. User clicks "Identify Violation"
5. Toast: "Violation identified"
6. Form resets and closes; new violation card appears under Active violations with status Identified
