# Make Counseling Referral

1. User navigates to Stewardship, Foreclosure Prevention tab, and opens an active case's detail panel
2. User expands the case card, and in the Counseling Referrals section enters a required Agency Name and confirms Referral Date (defaulted to today)
3. User clicks "Make Referral"
4. Toast: "Referral made"
5. Form resets; new referral appears in the list awaiting an outcome
