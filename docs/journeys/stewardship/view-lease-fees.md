# View Lease Fees

1. User navigates to Stewardship and clicks the Lease Fees tab (after Lease Stewardship and Foreclosure Prevention)
2. The table lists each lease with a balance due, most days overdue first: Homeowner, Home, Monthly Fee, Balance, Oldest Unpaid (the month of the oldest charge not fully paid, e.g. "February 2026") and Days Overdue (days since that charge fell due on the 1st)
3. User optionally switches the filter from "Balance due" (default) to "All leases"; then every active lease and every ended lease with a balance is listed, and a lease in credit shows its balance as a credit
4. User optionally types in the search box to filter by homeowner name or home label
5. If no lease has a balance due, empty state shows "No lease has a balance due."
6. User clicks a row; the ground lease opens in its detail panel, which has the Lease Fees section
