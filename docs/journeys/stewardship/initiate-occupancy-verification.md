# Initiate Occupancy Verification

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Occupancy Verification section, user clicks "+" (only available when no verification exists yet for the current year)
3. User optionally enters a Survey Deadline
4. User clicks "Start Verification"
5. Toast: "{year} occupancy verification initiated"
6. Form closes; section now shows the verification as Pending, awaiting homeowner response
