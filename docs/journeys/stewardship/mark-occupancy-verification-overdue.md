# Mark Occupancy Verification Overdue

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Occupancy Verification section, with a Pending verification for the current year, user enters Mark Overdue as of Date (defaulted to today)
3. User clicks "Mark Overdue"
4. Toast: "Verification marked overdue"
5. Verification moves to Overdue status
