# Verify Occupancy

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Occupancy Verification section, with a Submitted verification, user confirms Verified Date (defaulted to today)
3. User clicks "Verify"
4. Toast: "Occupancy verified"
5. Section shows a green confirmation: "Verified {date} — occupancy confirmed for {year}"
