# Cure Lease Violation

1. User navigates to Stewardship, Lease Stewardship tab, and opens a case's detail panel
2. In the Lease Violations section, user finds a NoticeIssued violation card
3. User confirms Cured Date (defaulted to today)
4. User clicks "Mark Cured"
5. Toast: "Violation cured"
6. Violation moves to Cured status and appears under Resolved violations history
