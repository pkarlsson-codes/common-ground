# View Foreclosure Prevention Cases

1. User navigates to Stewardship
2. User clicks the Foreclosure Prevention tab
3. Table shows Homeowner, Address, Status, Trigger, Delinquency, Open interventions (unresolved counseling referrals plus unresolved forbearance requests), Opened
4. User optionally pages through results with Previous/Next
5. If no cases exist, empty state shows "No foreclosure prevention cases" / "No open or active cases."
6. User clicks a row to open the case detail panel
