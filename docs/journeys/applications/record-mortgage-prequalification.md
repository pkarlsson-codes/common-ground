# Record Mortgage Prequalification

1. User navigates to Applications
2. User clicks a row for an application in the Submitted or Approved phase to open the detail panel
3. In the Buyer Preparation Checklist, user clicks "Record" (or "Update" if a prequalification already exists) next to Mortgage Prequalification
4. "Record Mortgage Prequalification" panel opens
5. User enters Lender Name, Approved Amount, and Expiry Date (all required)
6. User clicks "Record Prequalification" (disabled until all three fields are set)
7. Toast: "Mortgage prequalification recorded"
8. Panel closes, the household's Mortgage Prequalification checklist item is marked done showing lender name and expiry date, and the Mortgage Prequalification detail section reflects the new values
