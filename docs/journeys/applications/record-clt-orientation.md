# Record CLT Orientation

1. User navigates to Applications
2. User clicks a row for an application in the Submitted or Approved phase to open the detail panel
3. In the Buyer Preparation Checklist, user clicks "Record" next to CLT Orientation
4. "Record CLT Orientation" panel opens with Completed Date defaulted to today
5. User optionally adjusts Completed Date
6. User clicks "Record Orientation" (disabled until Completed Date is set)
7. Toast: "CLT orientation recorded"
8. Panel closes, the household's CLT Orientation checklist item is marked done
