# View Application Detail

1. User navigates to Applications and clicks a row in the Applications table, or clicks an "Application to decide" row on [Today](../today/work-through-today.md)
2. Detail panel opens titled with the household's primary contact, showing phase (Submitted, Approved, Selected, Denied, Withdrawn, or Removed), submitted at/by, primary contact phone, declared household size, declared annual income, declared accessibility need (as captured at submission). Phase-specific fields appear only when they apply: approved date when Approved or Selected, selected date when Selected, denial reason when Denied, withdrawal reason when Withdrawn, removed date, reason and note when Removed
3. "Open Household" (styled as a link, as are the other connected-record buttons) opens the household on the Households page, where its members and readiness (counseling, orientation, prequalification) are kept
4. If the applicant has been selected, the panel shows "Open Selected Land Parcel" and "Open Selected Home" links
5. When the household has been passed over, a Passed Over section lists each home selection where another household was chosen while this one could have been selected: the date, the selection method (Priority or Lottery), and an "Open Selection" button that opens that selection. It covers the household's earlier applications too. With no pass-overs the section is not shown.
6. A Workflow Actions section shows the actions available for the current phase: Submitted offers Approve Application, Deny Application, and Withdraw Application; Approved offers Remove from Waiting List and Withdraw Application; Approve Application is the primary button; Deny Application, Remove from Waiting List and Withdraw Application sit in a separate group below it, divided by a line, in red text; otherwise "No actions available for this phase" — choosing a household for a home is done through a [home selection](../home-selections/start-home-selection.md), not from the application
7. User closes the panel
