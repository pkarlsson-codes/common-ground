# View Application Detail

1. User navigates to Applications
2. User clicks a row in the Applications table
3. Detail panel opens titled with the household's primary contact, showing phase (Submitted, Approved, Selected, Denied, or Withdrawn), submitted at/by, primary contact phone, declared household size, declared annual income, declared accessibility need (as captured at submission), approved date, selected date, denial reason (if any), and withdrawal reason (if any)
4. "Open Household" opens the household on the Households page, where its members and readiness (counseling, orientation, prequalification) are kept
5. If the applicant has been selected, the panel shows "Open Selected Land Parcel" and "Open Selected Home" links
6. A Passed Over section lists each home selection where another household was chosen while this one could have been selected: the date, the selection method (Priority or Lottery), and an "Open Selection" button that opens that selection. It covers the household's earlier applications too. With no pass-overs it reads "This household has not been passed over for a home."
7. A Workflow Actions section shows the actions available for the current phase: Submitted offers Approve Application, Deny Application, and Withdraw Application; Approved offers Deny Application and Withdraw Application; otherwise "No actions available for this phase" — choosing a household for a home is done through a [home selection](../home-selections/start-home-selection.md), not from the application
8. User closes the panel
