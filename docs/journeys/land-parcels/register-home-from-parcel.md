# Register Home From Parcel

1. User navigates to Land Parcels, optionally searching by parcel number or address to narrow the table
2. User clicks a row to open the parcel detail panel
3. In the Homes section, user clicks "+ Register Home"
4. "Register Home" panel opens with Land Parcel field pre-filled and locked to the current parcel
