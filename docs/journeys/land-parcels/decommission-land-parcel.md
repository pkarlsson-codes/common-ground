# Decommission Land Parcel

1. User navigates to Land Parcels, optionally searching by parcel number or address to narrow the table
2. User clicks a row to open the parcel detail panel
3. User clicks the "···" actions menu
4. User clicks "Decommission"
5. Confirmation prompt appears: "Decommission this parcel? It will be marked inactive."
6. User clicks "Confirm"
7. Toast: "Parcel decommissioned"
8. Status badge in the panel updates to "Decommissioned"
9. The parcel drops out of the Land Parcels table, which hides decommissioned parcels unless "Show decommissioned" is checked
