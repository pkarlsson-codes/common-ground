# Initiate Development Project From Parcel

1. User navigates to Land Parcels
2. User clicks a row to open the parcel detail panel
3. In the Development Projects section, user clicks "+ Initiate Project"
4. "Initiate Development Project" panel opens with Land Parcel field pre-filled and locked to the current parcel
