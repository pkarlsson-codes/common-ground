# Register Land Parcel

1. User navigates to Land Parcels
2. User clicks "Register Parcel"
3. "Register Land Parcel" panel opens
4. User enters legal parcel number, address, area (acres), acquisition date, acquisition method, and optional covenant terms
5. User clicks "Register Parcel"
6. Toast: "Land parcel registered successfully"
7. Panel closes, new parcel appears in the Land Parcels table
