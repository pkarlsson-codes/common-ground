# Recommission Land Parcel

1. User navigates to Land Parcels
2. User checks "Show decommissioned" to reveal decommissioned parcels in the table (they're hidden by default), optionally searching by parcel number or address to narrow it
3. User clicks a decommissioned parcel's row to open the detail panel
4. User clicks the "···" actions menu
5. User clicks "Recommission"
6. Confirmation prompt appears: "Recommission this parcel? It will be marked active again."
7. User clicks "Confirm"
8. Toast: "Parcel recommissioned"
9. Status badge in the panel updates to "Active"
