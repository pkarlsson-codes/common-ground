# Start Home Selection

1. User navigates to Homes and opens the detail panel of a home at the Available stage
2. The Next Step card reads "Choose a household from the waiting list for this home.", followed by how many earlier selections were cancelled (if any)
3. User clicks "Start Selection" on the card
4. The selection page opens at Homes › Home Selection with every household on the [Waiting List](../waiting-list/view-waiting-list.md) as a candidate, their priority facts snapshotted as they were when the selection started

If the waiting list is empty, the card shows "The waiting list is empty, so there is no one to select from." and no selection is started.

A home has at most one open or completed selection. If someone else started one first, the start is rejected and the card shows "This home already has an open or completed selection." Once a selection is cancelled, or the purchase it led to fails or is withdrawn, a new one can be started.

When a purchase that came from a selection fails or is withdrawn, a new selection for the home is started automatically, so the home goes straight back to the Selection stage.
