# Start Home Selection

1. User navigates to Homes and opens the detail panel of a home with status Available
2. A Home Selection section reads "Choose a household from the waiting list for this home.", followed by how many earlier selections were cancelled (if any)
3. User clicks "Start Selection"
4. The selection page opens at Homes › Home Selection with every household on the [Waiting List](../waiting-list/view-waiting-list.md) as a candidate, their priority facts snapshotted as they were when the selection started

If the waiting list is empty, the section shows "The waiting list is empty, so there is no one to select from." and no selection is started.

A home has at most one open or completed selection. If someone else started one first, the start is rejected and the section shows "This home already has an open or completed selection." Once a selection is cancelled, a new one can be started.
