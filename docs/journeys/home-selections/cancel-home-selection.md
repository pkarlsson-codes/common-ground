# Cancel Home Selection

1. User opens an Open selection (see [View Home Selection](view-home-selection.md))
2. User clicks "Cancel Selection", for example because no candidate suits the home
3. "Cancel Selection" panel opens with the subtitle "Nobody is selected or passed over"
4. User enters a Reason
5. User clicks "Cancel Selection" (disabled until a reason is entered), or "Back" to keep the selection open
6. Toast: "Selection cancelled"
7. Panel closes and the selection becomes Cancelled, showing the reason, who cancelled it and when

Every candidate stays on the waiting list with no pass-over recorded. The home's detail panel goes back to offering "Start Selection" and counts the cancelled selection.
