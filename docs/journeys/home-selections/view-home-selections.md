# View Home Selections

1. User navigates to Home selections (under Work, and under My work for the Sales focus)
2. Table lists home selections across every home, newest first: Home (its label), Status (Open, Completed, Fell Through, or Cancelled), Candidates, Started (date), and Chosen Household (once completed)
3. User filters by status (All Statuses, Open, Completed, Fell Through, Cancelled); the default shows Open selections
4. User clicks a row to open the selection

A completed selection is marked Fell Through when the purchase it led to fails or is withdrawn; the home then gets a new selection automatically.
