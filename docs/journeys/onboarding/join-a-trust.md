# Join a Trust

For a colleague who received an invite link from a trust member.

1. User opens the invite link (`/invite/<token>`). If they are not signed in, they sign in or register on the sign-in page and come back to the link
2. The invite page shows "Join {trust name}" and the email the invite was made for
3. User clicks "Join Trust"
4. The user is added to the trust, their session is refreshed and they land on [Today](../today/work-through-today.md)
5. If the link was already used, cancelled or has expired, or doesn't exist, the page says "This invite link is no longer valid. Ask a member of the trust for a new one." with no Join button
6. If the user already belongs to a trust, the page says "You already belong to a trust." with a link into the app, and no Join button
