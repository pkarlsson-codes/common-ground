# Remove a Member

For when a staff member leaves the trust.

1. User clicks **Team** in the sidebar, under Settings
2. The Members table marks the user's own row "(you)". Every other row has a "Remove" button; the user's own row has none
3. User clicks "Remove" on a member's row. A dialog asks "Remove {name}?" and says they will lose access at once and can be invited again later
4. User clicks "Remove Member". A toast says "{name} removed" and the row leaves Members
5. The removed member's next action in the app fails: the page reloads and shows "You're not part of a trust yet". From there they can join with a new invite or create a trust

Continues in: [Invite Staff](invite-staff.md) (to add them back)
